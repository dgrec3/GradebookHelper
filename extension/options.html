Rows & colors

Lower strength gives softer colors and lets PowerTeacher's gray row stripes show through colored cells, so each student's row stays easy to follow.

Multiple matches

85

Colors go left to right: the grade color first, then Late / Missing, then any other code or flag (Medical, Exempt, Incomplete, Absent…). When off, a single color is shown: score code, then flag, then grade.

Assignment highlights

A score is in a band when it is at least Min and below Max. Leave Max blank for "and above". The first matching band from the top wins.

Final grade

Score codes

Color cells whose score or final grade is a special code from your district's grade scale (for example M for Medical). With splitting off, a code wins over flags and score bands.

Flags

L M

Tags appear for every flag that's set, whether or not its color is on below, and work with or without split highlighting.

Color cells that PowerTeacher has flagged. With splitting off, a flag wins over the score band, and if a cell has several flags the highest one in this list wins.
